# Esports Casa Apuesta

Proyecto academico para la materia de **Programacion WEB**. Frontend estatico con HTML5 y CSS3 (Flexbox, Grid y media queries) para una plataforma tematica de esports y pronosticos de demostracion.

## Como ver el sitio

1. Abre el archivo `index.html` en tu navegador (doble clic o arrastrar al navegador).
2. Navega con el menu superior y el pie de pagina.

No hace falta instalar dependencias en esta etapa.

## Estructura

```
Esports_Casa_Apuesta/
├── index.html
├── pages/          (eventos, login, registro, perfil, apuestas, pagos, retiros, historial, acerca-de, contacto)
├── css/
│   ├── styles.css
│   ├── layout.css
│   ├── components.css
│   └── responsive.css
└── assets/img/     (logo, hero, juegos, avatar)
```

## Identidad visual

- Fondo: `#0B1020`
- Acento: `#00D9FF`
- Secundario: `#7C3AED`
- Texto: `#FFFFFF`

## Aviso importante

Datos, saldos, cuotas y formularios son **ficticios**. No se procesa dinero real ni apuestas reales. Es solo interfaz para aprendizaje.
