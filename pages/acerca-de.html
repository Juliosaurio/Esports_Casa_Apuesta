Acerca del proyecto

Esports Casa Apuesta

Este sitio es un proyecto academico de la materia Programacion WEB. La tematica combina esports, torneos de videojuegos y una interfaz de pronosticos presentada unicamente con fines educativos.

Tecnologias usadas en esta etapa

  • HTML5 semantico para la estructura de paginas
  • CSS3 con variables, Flexbox, Grid y media queries
  • Diseno responsivo para escritorio, tablet y movil

Proximas etapas (planificadas)

JavaScript para validaciones e interaccion, Supabase para autenticacion y datos, y despliegue en Vercel. Esas partes aun no estan implementadas en esta version.

Todos los usuarios, saldos, cuotas y transacciones son ficticios. No se apuesta dinero real.
